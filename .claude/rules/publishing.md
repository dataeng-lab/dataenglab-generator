# Publishing Rules

- Do not publish to `dataenglab.com` without explicit user approval for the exact page and change.
- Discover available publishing capabilities fresh before publishing.
- Use only safe native content mechanisms. Do not use PHP execution, direct database access, custom CSS/JS injection, theme/plugin installs, or theme/plugin file edits.
- If a safe native content mechanism is not available, stop and report that.
- One approval covers one described live-site change only. Separate pages, listing updates, or unrelated changes need separate approval.
