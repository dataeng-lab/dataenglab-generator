# Core Project Rules

- Public and student-facing content must be English.
- Do not generate or use PHP, WordPress plugins, WordPress themes, shortcodes, Elementor HTML widgets, custom JavaScript, custom CSS, direct database changes, hosting credentials, or secrets.
- Do not edit theme/plugin files, run PHP, touch WordPress tables directly, or use a connector capability that does those things.
- Do not fabricate statistics, testimonials, URLs, credentials, tool behavior, validation results, review verdicts, Elementor import results, or live-site publishing results.
- Use Context7 MCP when available before writing version-sensitive claims, commands, imports, dependency choices, or examples for external technologies such as Airflow, dbt, Spark, pandas, Polars, DuckDB, PostgreSQL, pytest, Docker Compose, Kafka, or cloud SDKs.
- If Context7 is unavailable, continue from stable project knowledge and report that limitation.
