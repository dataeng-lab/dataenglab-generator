# Démarrage rapide

## Référence Elementor

Créez dans Elementor une page modèle contenant des conteneurs, titres, textes, boutons, cartes, icônes et accordéons. Exportez-la en JSON et placez-la dans :

```text
references/elementor-reference.json
```

Ajoutez aussi `references/homepage.png`.
