# Course Request

## Title
Build and Debug a Production-Style Airflow Pipeline

## Slug
airflow-pipeline

## Audience
Junior Data Engineers who understand Python and basic SQL.

## Level
Intermediate

## Estimated duration
4 hours

## Technologies
Apache Airflow, Python, PostgreSQL, Docker Compose, pytest

## Scenario
An e-commerce company receives daily order files. The pipeline is unreliable, creates duplicates and mishandles invalid records.

## Outcomes
Students must understand DAG structure, build idempotent tasks, configure dependencies/retries, validate data, quarantine invalid rows, deduplicate, load PostgreSQL, test DAGs and diagnose failures.

## Lab tasks
1. Repair the DAG.
2. Implement CSV extraction.
3. Validate required fields.
4. Quarantine invalid records.
5. Deduplicate orders.
6. Load PostgreSQL.
7. Configure retries.
8. Make the pipeline idempotent.
9. Pass automated tests.

## Deliverables
Elementor JSON when reference is valid, Tutor LMS curriculum, lessons, two quizzes, student lab, tests, instructor solution, troubleshooting and student ZIP. No PHP or deployment.
