## Sequencing notes
- Lessons 1.1–1.2 build the conceptual model (why validate, how to detect problems) before any code is written end to end.
- Quiz 1.3 checks concept retention before students move to implementation.
- Lesson 1.4 walks through the full clean/quarantine/deduplicate pattern that the lab requires.
- Quiz 1.5 checks implementation understanding immediately before the lab.
- The lab (1.6) is the practical deliverable and consumes the majority of course time, in line with the 50%+ practical-time requirement.
